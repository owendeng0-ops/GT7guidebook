# GT7 Track Atlas V1.5: License AI Coach

## Goal

V1.5 turns the V1.4 telemetry archive into a first coaching loop for license-test gold attempts:

```text
PS5 / GT7 UDP telemetry -> local telemetry-agent -> browser trace archive -> lap analysis -> actionable coaching notes
```

The assistant does not control the PS5 or drive for the user. It reads the user's real lap data, aligns it to the selected or matched layout, and tells the user where to gain time.

## Current MVP

- Uses the existing local WebSocket stream from `telemetry-agent`.
- Stores completed lap traces in IndexedDB.
- Detects major braking zones from brake input.
- Estimates coasting time, full-throttle ratio, heavy-brake zones, exit-throttle delay, and large entry-speed losses.
- Maps braking-zone advice to the current or matched layout's corner order when layout data is available.
- Shows an `AI Coach` block on pending telemetry laps and saves the same coach notes into archived training sessions.

## Coaching Signals

The first pass is rule based and intentionally explainable:

- **Exit throttle delay**: time between brake release and returning to strong throttle.
- **Coasting**: samples where both throttle and brake are near zero.
- **Entry speed loss**: speed drop between braking start and minimum corner speed.
- **Heavy brake hold**: repeated zones with high brake pressure held for too long.
- **Full-throttle ratio**: how much of the lap is spent at 95%+ throttle.
- **Brake event count**: whether the lap has many more braking events than the layout has corners.

Each item produces one practice instruction, for example earlier staged throttle at corner exit or smoother brake release before the apex.
